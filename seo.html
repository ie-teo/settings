SEO Конспект

Подробный SEO-конспект по запуску, анализу и продвижению сайта. Подходит как для новых проектов, так и для уже существующих сайтов.

1. Базовые действия перед запуском сайта

  • Проверить скорость сайта через Google PageSpeed Insights.
  • Подключить сайт к Google Search Console.
  • Добавить сайт в Google Analytics.
  • Перед покупкой домена проверить историю сайта через Web Archive.
  • Проверить домен на спам и санкции.
  • Создать sitemap.xml.
  • Создать robots.txt.
  • Настроить HTTPS.
  • Внедрить микроразметку Schema.org.
  • Настроить favicon.
  • Проверить мобильную адаптацию сайта.
  • Оптимизировать изображения.
  • Добавить Open Graph разметку для соцсетей.
  • Развивать Facebook и публиковать посты на английском языке.
Идея проекта:
Создать сервис автоматической генерации sitemap.xml и robots.txt.

2. SEO Анализ сайта

Определение тематики

  • Определить основную тематику сайта.
  • Определить целевую аудиторию.
  • Определить коммерческий или информационный тип сайта.
  • Собрать основные ключевые запросы.

Анализ конкурентов

  • Выписать прямых конкурентов.
  • Изучить их структуру сайта.
  • Проверить количество страниц.
  • Изучить их sitemap.xml.
  • Посмотреть какие страницы получают трафик.
  • Анализировать Title и Description конкурентов.
Хорошая структура сайта часто строится на основе структуры успешных конкурентов.

История сайта

Перед запуском домена обязательно проверить:

  • Был ли сайт под санкциями.
  • Не использовался ли домен под спам.
  • Какой контент был размещен ранее.

Иерархия сайта

  • Продумать структуру категорий.
  • Разделить страницы по ключевым запросам.
  • Сделать логичную вложенность URL.
  • Избегать слишком глубокой структуры.

Поисковый индекс

  • Проверить индексируются ли страницы.
  • Проверить наличие дублей страниц.
  • Следить за canonical URL.
  • Проверять индексацию в режиме инкогнито.

3. Кластеризация запросов

Кластеризация — это группировка поисковых запросов по смыслу.

  • Разделять запросы по категориям.
  • Создавать отдельные страницы под группы запросов.
  • Избегать конкуренции страниц между собой.
  • Использовать long-tail запросы.
Одна страница = одна группа запросов.

4. Съем позиций и анализ трафика

Съем позиций

  • Использовать Topvisor.
  • Проверять позиции регулярно.
  • Следить за ростом и падением страниц.
  • Сравнивать позиции с конкурентами.

Анализ трафика

  • Создать таблицу ключевых запросов.
  • Записывать позиции страниц.
  • Отслеживать CTR.
  • Анализировать источники трафика.
  • Проверять поведенческие факторы.
Анализ позиций лучше делать минимум раз в месяц.

5. Постановка ТЗ

Техническое задание для новых страниц

  • Добавлять новые SEO-страницы.
  • Оптимизировать заголовки H1.
  • Прописывать Title и Description.
  • Добавлять ключевые слова естественно.
  • Улучшать внутреннюю перелинковку.

ТЗ по микроразметке

  • Изучать Schema.org.
  • Добавлять FAQ-разметку.
  • Добавлять Article-разметку.
  • Размечать хлебные крошки.

6. Ссылочное продвижение

SeoWizard

  • Аренда ссылок.
  • Покупка вечных ссылок.
  • Социальные сигналы.
  • Крауд-маркетинг.
  • Сквозные ссылки.

Gogetlinks

  • Покупка вечных ссылок.
  • Размещение статей.

Sape

  • Арендные ссылки.
  • Массовое ссылочное продвижение.
Нельзя резко наращивать ссылочную массу. Это может привести к санкциям Google.

Стратегия ссылочного продвижения

  • Наращивать ссылки постепенно.
  • Использовать разные типы ссылок.
  • Следить за качеством доноров.
  • Избегать спамных сайтов.

7. Технический аудит

Проверка сайта

  • Проверка ошибок сайта.
  • Проверка скорости загрузки.
  • Проверка мобильной версии.
  • Проверка Core Web Vitals.
  • Проверка HTTPS.

Аудит внутренней оптимизации

  • Использовать SeoProfiler.
  • Проверять мета-теги.
  • Проверять перелинковку.
  • Находить битые ссылки.
  • Искать дубли страниц.

Аудит внешней оптимизации

  • Использовать Ahrefs.
  • Анализировать ссылочный профиль.
  • Удалять токсичные ссылки.
  • Изучать ссылки конкурентов.

8. Полезные SEO сервисы

Google Search Console

Контроль индексации и ошибок сайта.

Google PageSpeed

Анализ скорости сайта.

Topvisor

Отслеживание позиций.

Ahrefs

Анализ ссылок и конкурентов.

SeoProfiler

Внутренний SEO аудит.

Web Archive

Проверка истории домена.

9. Главные SEO принципы

  • Контент должен быть полезным.
  • Сайт должен быть быстрым.
  • Структура сайта должна быть логичной.
  • Нельзя делать переоптимизацию.
  • SEO — это долгосрочная стратегия.
  • Нужно регулярно обновлять контент.
  • Поведенческие факторы очень важны.
  • Качество ссылок важнее количества.
SEO — это постоянная работа над качеством сайта, контентом и авторитетностью домена.
